# Changelog

## 0.1.0 - 2026-11-07

First public release.

- Static documentation generator for a folder of Markdown or MDX: `beacon build` and `beacon dev`.
- Three-column layout, light and dark themes, syntax highlighting, and serverless search (Pagefind).
- Sidebar sections from top-level folders, optional collapsible folders, and previous/next page links.
- Multi-language sites with a language switcher.
- Reader features: linked headings, copy page as Markdown, per-page Markdown output, `llms.txt`, edit-page link.
- Sitemap, robots.txt, Open Graph image, and reduced-motion support.
