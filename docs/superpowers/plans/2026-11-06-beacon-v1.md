# Beacon v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `beacon build` turns a `content/` folder of `.md`/`.mdx` into a fast static docs site in Pier's visual identity, and Pier's five user-facing docs build unmodified.

**Architecture:** One npm package (`@monelyx/beacon`, scope still to confirm) holding a CLI and a bundled Astro project. The CLI loads `beacon.config.*`, then runs Astro programmatically against the user's `content/`, passing config through a Vite virtual module. Navigation is derived from the folder tree. Interactivity is limited to lazy React islands; everything else is static HTML and plain CSS.

**Tech Stack:** Node >=22, pnpm, Astro, `@astrojs/mdx`, `@astrojs/react` (phase 4), Shiki (via Astro), Pagefind (phase 5), plain CSS. Tests use `node:test` and plain ESM JS with JSDoc, so there is no test or TypeScript dependency to justify. If you want TypeScript or Vitest, that needs an ADR.

**Spec:** `docs/superpowers/specs/2026-11-06-beacon-design.md`

## Global Constraints

- Everything in English (code, comments, logs, errors, UI copy, tests, commits, docs). No i18n.
- Conventional Commits, one commit per task, **no `Co-Authored-By` or any attribution lines** (AGENTS.md rule 10).
- No dependency without an ADR in `docs/adr/NNNN-<name>.md` committed **before** the dependency. Stack changes need an ADR and notifying the owner.
- No Tailwind or UI kit. Plain CSS with custom properties, tokens vendored from Pier's `landing/src/styles/tokens.css`.
- Fonts: Bricolage Grotesque self-hosted via Fontsource (headings); system stacks for body and code. Never Google Fonts.
- Node `>=22`, pnpm.
- Budgets (gzipped), measured not assumed: plain page < 30 KB JS and < 20 KB CSS; inline theme script < 1 KB; Lighthouse 100 for performance, accessibility and SEO. Measured on a plain page, then again with search open. A missed budget is documented with options, never relaxed.
- Config: required `site`; `title`, `accent` (default orange) and `logo` are the only other fields in v1.
- Content: `.md` and `.mdx` accepted; frontmatter optional (`title`, `description`, `order`); title falls back to the first `# heading`.
- Accent is one config value. Light and dark themes. Code blocks are dark in both.
- One default OG image per site, not per page.
- End of each phase: publish the AGENTS.md rule 8 summary (done, measured vs budgets, open) as `docs/superpowers/plans/summaries/phase-N.md`.

## Review Focus

Input classes the spec implies but does not test. The owning task adds the test.

1. **Raw HTML, `{` and `<` in `.md` files.** Plain `.md` must not be parsed as MDX, or Pier-style prose breaks. Owner: Task 2.1.
2. **Relative links to pages outside `content/`.** Pier's docs link to `troubleshooting.md` and `adr/...`, which are not in scope. The build must not crash or ship dead links silently. Owner: Task 2.2.
3. **Slug collisions and odd filenames.** `a.md` next to `a/index.md`, spaces, uppercase, non-ASCII. Expect a clear error naming both files, not an overwritten page. Owner: Task 1.3.
4. **Bad config.** Missing `site`, non-URL `site`, invalid `accent`, `accent` with poor contrast. Expect a one-line error naming the field. Owner: Task 1.2.
5. **Empty or missing `content/`.** Expect a clear error and a non-zero exit, not an empty site. Owner: Task 1.3.

## File structure

```
package.json, pnpm-workspace not needed (single package)
bin/beacon.js                CLI entry: parses `build` (and later `dev`)
src/cli/config.js            loadConfig(root) -> BeaconConfig, validates
src/cli/content.js           scanContent(dir) -> Page[], buildNav(pages) -> NavNode[]
src/cli/build.js             build(root) runs Astro programmatically
src/site/                    the bundled Astro project
  layouts/Docs.astro         three-column layout
  pages/[...slug].astro      renders one Page
  components/                Sidebar, Toc, Breadcrumb (static); islands from phase 4
  styles/tokens.css, base.css, layout.css
test/                        node:test suites and fixtures/
scripts/measure-budget.mjs   gzipped JS/CSS per page from dist/
docs/adr/                    one ADR per dependency
```

Shared types (JSDoc): `BeaconConfig = {site: string, title: string, accent: string, logo?: string}`; `Page = {slug: string, file: string, title: string, description?: string, order?: number}`; `NavNode = {label: string, href?: string, children: NavNode[]}`.
